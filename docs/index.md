# All Repo Info

Central badge configuration and documentation hub for the **MJP-76** Home
Assistant repositories.

Every repo's README is kept in sync with a single source of truth. This site
is where you can browse all of them from one place.

## What this site is

- **Repo matrix** — every repository, its current version, and a link to its
  own MkDocs site.
- **How syncing works** — how `repo_badges.json` and `sync_repos.py` keep the
  badge and support-me sections in every README in step.
